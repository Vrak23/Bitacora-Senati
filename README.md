# 📋 Bitácora & Cuaderno de Informes SENATI (Formación Dual)

Aplicación web interactiva para gestionar y registrar las 16 semanas de prácticas del programa de Formación Dual en SENATI (Informática y Desarrollo de Aplicaciones Web).

## 🚀 Funcionalidades
- **Gestión de 16 Semanas**: Registro semanal con persistencia en localStorage.
- **Cálculo Automático de Horas**: Totaliza horas de lunes a sábado.
- **Asistente de Redacción Técnica**: Plantillas prediseñadas para desarrollo de software.
- **Exportación Oficial A4 (Formato DUAL-04)**: Impresión y guardado en PDF listo para firmas.
- **Tema Oscuro & 100% Responsive**: Interfaz moderna adaptable a celulares y escritorios.

## 🛠️ Tecnologías
- Vite 5
- HTML5 / CSS3
- JavaScript (ES Modules)
